# LinguaCapture

LinguaCapture is an iOS application designed for language learners. It provides an immediate, context-aware tool to capture, understand, and memorize foreign language vocabulary encountered in the everyday environment.

## Features (MVP)

*   **Camera Capture:** Capture images of text using the device's camera.
*   **Vocabulary List:** View all captured words in a central list.
*   **Local Storage:** All data is stored locally on the device using SwiftData.

## Technology Stack

*   **Platform:** iOS
*   **Language:** Swift
*   **UI:** SwiftUI
*   **Database:** SwiftData
*   **Camera:** AVFoundation

## How to Build

1.  Open the project in Xcode.
2.  Select a target device or simulator.
3.  Build and run the project (Cmd+R).
